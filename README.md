# Фитнес‑трекер (Go)

Модуль фитнес‑трекера для расчёта показателей активности при беге, ходьбе и тренировках. Реализован на языке Go с использованием модульной архитектуры.

## Структура проекта

Модуль состоит из пяти пакетов:

1. **`spentenergy`** — расчёт средней скорости, дистанции и потраченной энергии.
2. **`personaldata`** — структура с персональными данными пользователя (`Name`, `Weight`, `Height`) и метод для их вывода на экран.
3. **`trainings`** — работа с данными о тренировках:
   * структура с данными о количестве шагов, длительности тренировки и типе активности;
   * встроенная структура с персональными данными;
   * методы для парсинга строки с данными и формирования строки с информацией о тренировке.
4. **`daysteps`** — работа с данными о дневной активности (прогулках):
   * структура с данными о количестве шагов и длительности прогулки;
   * встроенная структура с персональными данными;
   * методы для парсинга строки и формирования строки с информацией о прогулках.
5. **`actioninfo`** — пакет с интерфейсом `ActionInfo`, включающим два метода:
   * `Parse(datastring string) error`;
   * `ActionInfo() (string, error)`.

## Как использовать
Данные пользователя уже определены в пакете main
Для запуска использовать команту go run main.go
